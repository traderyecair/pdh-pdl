# pdh-pdl

Trading Performance & Statistical Analysis Dashboard.

## Features
- **Win Rate & Profit/Loss Series**: In-depth analysis of consecutive gains and losses.
- **Monthly Net R:R Heatmap**: Periodical strength estimation based on risk-to-reward ratios.
- **Dynamic Charting**: Performance metrics adjusted dynamically for screens (1080p, 2K, etc.).
- **Modern Dark Theme**: Rich glassmorphism aesthetics.

## Tech Stack
- React
- TypeScript
- Vite
- Chart.js
- CSS Variables (Custom Styling)

## Deployment
Hosted on GitHub Pages via GitHub Actions.
